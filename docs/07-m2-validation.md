## 3. 模型边界

M1 已用 OpenRouter 免费 Nemotron 完成真实代码任务和 4 项测试，证据保留在 [M1 报告](05-m1-validation.md)。本轮不重复消耗模型额度；新增持续任务适配器的回调中断、停止与结果保护通过受控进程测试覆盖，未新增一轮 M2 Web 发起的真实模型推理。

本轮真实 Docker 验收使用显式 OpenCode 免费 profile，只做服务、技能和代码工作区操作，不提交推理。M2 默认业务模型仍沿用 M1 验证的 OpenRouter 模型，由运行时配置和现有凭据决定是否可执行。
