## 模型验证边界

当前实例没有配置模型凭据，运行策略也未包含模型服务域名。此轮未进行在线模型调用，不要求聊天传递密钥。

验收 Runner 的分析、开发及评审报告均为明确标记的受控输入；开发改动仅追加“不是模型生成”的样例注释，评审问题同样标记为受控问题。生产 Runner 使用 OpenCode 实际执行路径，未引入模拟模型开关。

已有 M1 真实模型证据继续有效，但不等于本轮默认流程已经完成在线多模型验收。后续应在配置好的本机运行同一流程，确认 Superpowers 最终报告结构、不同模型可用性及实际缺陷发现，再将 M3 草稿转为正式验收。业务项目、多项目全景分析、概要设计和测试材料不在此轮验收结论内。
