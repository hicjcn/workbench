已将连接重置等传输异常归为可重新探测的控制错误，增加对应回归测试。修复后第二轮双容器验证全部通过，原失败记录保存在被 Git 忽略的本地证据目录。

随后补充持久化 Agent 配置目录的软链接校验及私有临时文件原子写入，防止容器内持久化内容在宿主机重建时被当成可信路径。16 项回归测试及第三轮真实双容器验证全部通过。
