## 复现

各命令使用尚不存在的独立验证目录。需要已安装服务端、PostgreSQL 和浏览器依赖、Chromium，以及已有的 `agent-workbench-m1:local`、`postgres:17-bookworm` 镜像：

```bash
.venv/bin/python -m unittest discover -s tests -v
npm ci --prefix web
npm run --prefix web build
node --test poc/sample-project/server.test.mjs
.venv/bin/python poc/verify_delivery.py --root .local-data/m5-qa-new
.venv/bin/python poc/verify_postgres.py --root .local-data/m5-postgres-new
.venv/bin/python poc/verify_upgrade.py \
  --database /path/to/existing-m4/workbench.db --root .local-data/m5-upgrade-new
```

验收脚本会在 finally 中停止自身服务，清理自身验证目录可核实的托管资源；保留证据和代码。脚本中的受控结果只用于验收，不注入正式 Runner 的模型执行。
