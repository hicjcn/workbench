## 验证边界

浏览器使用真实页面 → API → SQLite → 独立验收 Runner → 只读 Docker → 页面与文件下载。M3 前置结果和 M4 文档生成输出均明确标记为受控数据；测试结果是带 `fixture://` 证据的受控登记，未执行用户业务测试或真实性能压测。

生产 Runner 没有模拟模型开关。当前实例没有配置模型凭据，网络自定义允许域名为空，因此没有新增在线推理。M1 的真实模型证据保留，但不作为本轮在线概要设计/测试单生成证据。OpenCode stdin 输入能力依据固定 v1.19.4 源码核实，并以受控子进程测试检查传输与失败保护。

主管结论由开发者登记，不代表系统直接连接或认证主管身份。外部证据只保存引用，不自动下载附件或发送消息。材料包包含本轮最新正文及记录，完整源码、全部历史正文与全项目交付由 M5 继续推进。
